# java-lotto-precourse

**기능 구현 사항 명세**

**입력**

- [x]  로또 구입 금액
- [x]  당첨 번호
- [x]  보너스 번호

**서비스 로직**

- [x]  로또 구매 수량 계산
    - 로또 구입 금액을 1,000원으로 나눔
- [x]  로또 번호 생성
    - 소수점 둘째 자리에서 반올림
    - 로또 번호는 **오름차순**으로 정렬
- [ ]  당첨 내역
    - 당첨 번호 & 보너스 번호와 로또 번호 비교
        - 발행된 로또 리스트를 순회하며 당첨 번호 포함 개수 확인
        - 당첨 시, Rank를 Key로 가지는 Map의 Value에 +1
        - 만약 당첨 번호 포함 개수가 5라면, 보너스 번호도 검사
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- [ ]  수익률
    - 당첨 등수 * 해당 금액을 모두 더한 값을 출력

**출력**

- [x]  로또 수량 및 번호

  ```
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  [7, 11, 16, 35, 36, 44]
  [1, 8, 11, 31, 41, 42]
  [13, 14, 16, 38, 42, 45]
  [7, 11, 30, 40, 42, 43]
  [2, 13, 22, 32, 38, 45]
  [1, 3, 5, 14, 22, 45]
  ```

- [ ]  당첨 내역

  ```
  당첨 통계
  ---
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  ```

- [ ]  수익률

  ```
  총 수익률은 62.5%입니다.
  ```

- [ ]  에러 문구 출력

  ```prolog
  [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  ```

    - 기본 에러 문구로 통일하고, 추후 케이스별로 분리

      [ERROR] 입력값이 잘못되었습니다. 다시 입력해주세요.

    - [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.

**예외**

- 사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시킨다
- "[ERROR]"로 시작하는 에러 메시지를 출력
- 그 부분부터 **입력을 다시 받는다**

- 로또 구매 금액
    - [x]  1,000원 단위로 나눠 떨어지는지
- 당첨 번호
    - [ ]  1부터 45 사이의 숫자인지
    - [ ]  6개가 맞는지
    - [ ]  중복이 있는지
- 보너스 번호
    - [ ]  1부터 45 사이의 숫자인지
    - [ ]  추후 추가
