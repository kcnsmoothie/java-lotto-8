# java-lotto-precourse

# 🎰 로또 프로그램 (Lotto Program)

## 📋 구현 기능 목록

핵심 기능 위주로 정리하고 하위 조건은 세부적으로 기술했습니다.

### 🧾 입력

* 로또 구입 금액을 입력받는다
    * 구분자 기준으로 앞뒤 공백 제거
* 당첨 번호를 입력받는다
* 보너스 번호를 입력받는다

---

### 📤 출력

* 발행된 로또 수량 & 번호를 출력한다
* 당첨 내역을 출력한다
* 수익률을 출력한다

---

### ⚙️ 기능

* **입력값 저장**

    * 구입 금액을 1000원 단위로 나누어 발행 수량을 계산하는 기능
    * 입력받은 당첨 번호 저장하는 기능
      * 구분자 단위로 구분
      * 6개가 들어가는 컬렉션에 저장
    * 보너스 번호를 저장하는 기능
* **로또 발행 기능**

    * 1~45 사이의 중복되지 않는 숫자 6개로 구성된 로또 1개 발행
    * 오름차순 정렬
    * 발행 수량만큼 로또 번호 발행
* **당첨 내역 계산 기능**

    * 구매한 로또 번호와 당첨 번호를 비교하여 등수 계산
* **수익률 계산 기능**

    * 소수점 둘째 자리에서 반올림하여 계산

---

### 고민해야할 사항

* 금액입력은 입력 자료형과 맞지 않는 자료형 검사는 int형 변환 과정에서 발생할텐데 어떻게 처리할까
* 

---

### ⚠️ 예외 처리 규칙

* 에러 문구는 반드시 **`[ERROR]`** 로 시작해야 한다.
* 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 발생
* `[ERROR]` 메시지 출력 후 **해당 입력부터 다시 받는다**

#### 공통 예외 기준

* 입력 자료형 불일치
* 공백 혹은 null 값 입력
* 숫자 범위 벗어남

#### 유연하게 허용되는 예외

* 공백 포함한 정상 입력 (예: `" 1 , 2 , 3 , 4 , 5 , 6 "` → 정상 처리)

---

#### 로또 구입 금액 입력 예외

* 숫자가 아닌 경우
* 공백 혹은 null 입력
* 1,000원 단위가 아닐 경우

#### 당첨 번호 입력 예외

* 숫자가 아닌 경우
* 공백 혹은 null 입력
* 숫자 범위 1~45 이탈
* 6개 미만 입력
* 중복된 값 입력

#### 보너스 번호 입력 예외

* 숫자가 아닌 경우
* 공백 혹은 null 입력
* 숫자 범위 1~45 이탈
* 당첨 번호와 중복된 값 입력

---
