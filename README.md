# java-lotto-precourse

## 기능 구현 사항

**입력**

- [ ]  로또 구입금액
- [ ]  당첨 번호
- [ ]  보너스 번호

**핵심 기능**

- [ ]  로또 구입금액에 따른 수량 계산 기능
- [ ]  로또 번호 랜덤 발행 기능
    - N개 만큼 발행
    - 오름차순 정렬
- [ ]  당첨 내역 계산 기능
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- [ ]  수익률 계산 기능
    - 당첨금액 / 구입금액 (반올림)

**출력**

- [ ]  로또 수량
- [ ]  로또 번호(오름차순 정렬)
- [ ]  당첨 내역
- [ ]  수익률

**예외**

잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 **그 부분부터 입력을 다시 받는다.**

**로또 구입금액**

- 빈 값 혹은 NULL일 때
- 숫자가 아닌 문자열을 입력했을 때
- 1000원 단위가 아닐 때

**당첨 번호**

- 빈 값 혹은 NULL일 때
- 숫자가 아닌 문자열을 입력했을 때
- 1~45 사이의 숫자가 아닐 때
- 중복된 숫자를 입력했을 때
- 입력한 숫자가 6개 이상일 때

**보너스 번호**

- 빈 값 혹은 NULL일 때
- 숫자가 아닌 문자열을 입력했을 때
- 1~45 사이의 숫자가 아닐 때
- 당첨번호와 중복된 숫자를 입력했을 때
